# Global-Sales-Performance
Enterprise-wide sales analytics platform tracking sales performance, customer behavior, regional trends, inventory, and revenue KPIs across multiple business units.
Built SQL extraction pipelines and ETL processes to clean and transform transactional data at scale.
Designed executive-facing Tableau dashboards and interactive visualizations for sales trends and profitability.
Automated daily sales reports and KPI scorecards using Excel VBA, improving turnaround for business teams.
Improved dashboard load performance through SQL query optimization.
